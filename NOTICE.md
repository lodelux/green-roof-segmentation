# Project provenance

This repository is a cleaned, standalone presentation of the semantic-segmentation component from **Green Roofs in Milan**, a two-person university project completed in 2025 by Lorenzo De Luca and Edoardo Guida.

The original collaborative repository, which also contains a separate optimization component, is available at:

https://github.com/eddrive/Green-Roofs-in-Milan

This repository intentionally contains only the segmentation work. No license is granted here; reuse requires permission from the relevant copyright holders.

The source roof polygons are published by the Municipality of Milan under a Creative Commons Attribution license. Aerial imagery is not redistributed in this standalone repository.
